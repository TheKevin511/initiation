I. Introduction

AContexte

L'ordinateur est devenu un outil de base dans presque tous les domaines : études, travail, commerce, santé, administration, communication et loisirs. Inscriptions en ligne, recherche d'emploi, paiements, cours à distance : tout passe aujourd'hui par un écran.

Savoir s'en servir n'est donc plus un luxe mais une compétence de base, au même titre que lire et écrire. Une personne à l'aise avec son ordinateur travaille plus vite, fait moins d'erreurs et s'adapte plus facilement aux nouveaux outils numériques.

BQu'est-ce qu'un ordinateur ?

Un ordinateur est une machine électronique programmable qui reçoit des informations, les traite, les conserve et les restitue. Son fonctionnement suit toujours le même cycle :

  • Entrée : vous donnez des informations à la machine avec le clavier, la souris, un micro ou une clé USB.
  • Traitement : le processeur effectue les calculs et exécute les instructions.
  • Stockage : les données sont conservées sur le disque dur ou le SSD pour être retrouvées plus tard.
  • Sortie : le résultat s'affiche sur l'écran, s'imprime ou passe par les haut-parleurs.

CQu'est-ce que Windows ?

Windows est le système d'exploitation créé par Microsoft. C'est le programme principal qui démarre avec l'ordinateur et qui permet de s'en servir sans connaître le langage de la machine.

  • Interface graphique : vous utilisez des fenêtres, des icônes et des menus plutôt que des lignes de commandes compliquées.
  • Gestion des ressources : Windows répartit la mémoire, le processeur et le stockage entre les programmes ouverts.
  • Compatibilité : la plupart des logiciels et périphériques du marché fonctionnent avec Windows.
  • Versions : Windows 10 et Windows 11 sont les plus répandues ; leur fonctionnement de base est très proche, donc ce cours s'applique aux deux.

DPourquoi apprendre à l'utiliser ?

  • Gagner du temps : connaître les bons gestes et les raccourcis accélère toutes les tâches.
  • Être autonome : on règle soi-même les petits problèmes sans dépendre d'un tiers.
  • Protéger ses données : de bonnes habitudes évitent la perte de fichiers et les arnaques en ligne.
  • Préparer la suite : Word, Excel, la programmation ou le marketing digital demandent de maîtriser ces bases.
  • Améliorer ses chances professionnelles : presque tous les métiers demandent aujourd'hui un minimum de culture informatique.

EObjectifs

À la fin de ce cours, vous serez capable de :

  • Connaître les composants : nommer et décrire le rôle de chaque pièce de la machine.
  • Allumer et éteindre correctement : éviter la perte de données et les pannes.
  • Se repérer dans Windows : utiliser bureau, menu Démarrer et fenêtres sans hésiter.
  • Gérer ses fichiers : créer, ranger et retrouver ses documents rapidement.
  • Naviguer en sécurité : se connecter à Internet en protégeant ses informations.

FPublic et prérequis

  • Public : étudiants, débutants, adultes en reconversion et toute personne qui veut apprendre les bases.
  • Prérequis : aucun, il suffit de savoir lire et d'avoir un ordinateur Windows à portée de main.
  • Durée conseillée : environ 3 heures, réparties en plusieurs séances pour mieux retenir.

Partie II

II. Développement

1Comprendre l'ordinateur

A. Le matériel (hardware)

  • Unité centrale : le « cerveau » qui contient le processeur, la RAM et le stockage et effectue tous les calculs.
  • Écran : affiche les informations et vos actions.
  • Clavier et souris : vos outils pour saisir du texte et donner des ordres.
  • Périphériques : appareils ajoutés (imprimante, clé USB, casque, webcam) qui étendent les possibilités.

B. Les logiciels (software)

  • Système d'exploitation (Windows) : le programme principal qui fait le lien entre vous et la machine.
  • Applications : programmes pour une tâche précise (Word pour écrire, Excel pour calculer, un navigateur pour Internet).
RAM = mémoire de travail, effacée à l'extinction. Disque dur/SSD = stockage permanent de vos fichiers.

2Allumer et éteindre

A. Allumer

  1. Brancher : vérifiez l'alimentation ou la batterie.
  2. Appuyer sur le bouton d'alimentation : le système démarre.
  3. Attendre l'écran de connexion : Windows charge, patientez sans rappuyer.
  4. Se connecter : entrez mot de passe ou PIN pour ouvrir votre session.

B. Éteindre proprement

  1. Enregistrer et fermer : sauvegardez votre travail et quittez les applications.
  2. Démarrer → Alimentation → Arrêter : Windows ferme tout correctement avant de s'éteindre.
OptionEffet
ArrêterÉteint complètement
RedémarrerÉteint puis rallume, utile en cas de blocage
Mettre en veillePause rapide, la session reste ouverte
Couper le courant brutalement peut faire perdre des données ou abîmer le système.

3Découvrir le bureau Windows

A. Les éléments du bureau

  • Icônes : raccourcis pour ouvrir un programme ou un dossier d'un double-clic.
  • Barre des tâches : affiche les applications ouvertes ou épinglées et permet de passer de l'une à l'autre.
  • Bouton Démarrer : porte d'accès aux applications, aux paramètres et à l'arrêt.
  • Zone de notification : heure, Wi-Fi, volume et batterie.

B. Pratique

  1. Ouvrir Démarrer et chercher « Bloc-notes » : la recherche est le moyen le plus rapide de trouver une application.
  2. Repérer Réduire / Agrandir / Fermer : ces trois boutons contrôlent la taille de la fenêtre.
  3. Alterner avec Alt+Tab : passer d'une fenêtre à l'autre sans la souris.

4Gérer fichiers et dossiers

A. Vocabulaire

  • Fichier : un document (texte, photo, vidéo).
  • Dossier : un « tiroir » qui regroupe des fichiers.
  • Explorateur de fichiers : l'outil pour naviguer, ouvert avec Windows+E.

B. Les actions de base

  1. Créer : clic droit → Nouveau → Dossier.
  2. Renommer (F2) : change le nom sans toucher au contenu.
  3. Copier (Ctrl+C puis Ctrl+V) : crée un double ailleurs, l'original reste.
  4. Déplacer (Ctrl+X puis Ctrl+V) : change l'emplacement du fichier.
  5. Supprimer (Suppr) : envoie le fichier à la Corbeille, d'où on peut le restaurer.

C. Bonnes pratiques

  • Noms clairs : par exemple Cours_Marketing_Chap1, pour se retrouver facilement.
  • Un dossier par matière : garde l'ensemble organisé.
  • Sauvegardes : copie sur clé USB ou cloud pour ne rien perdre en cas de panne.

5Les paramètres essentiels

Ouvrez Démarrer → Paramètres ou Windows+I.

  • Système : réglages d'affichage, de son et de batterie.
  • Réseau et Internet : connexion Wi-Fi.
  • Personnalisation : fond d'écran et thème pour adapter l'aspect.
  • Comptes : mot de passe et code PIN de votre session.
  • Heure et langue : fuseau horaire et clavier (AZERTY).
  • Windows Update : installe les mises à jour qui corrigent les failles de sécurité.

6Internet et sécurité

A. Se connecter au Wi-Fi

  1. Cliquer sur l'icône réseau : en bas à droite, dans la zone de notification.
  2. Choisir le réseau : sélectionnez le vôtre dans la liste.
  3. Saisir le mot de passe : puis « Se connecter ».

B. Naviguer

  • Navigateur : Chrome, Edge ou Firefox, le logiciel pour visiter les sites.
  • Barre d'adresse : tapez une adresse ou une recherche.
  • Favoris (Ctrl+D) : retrouver un site en un clic.

C. Règles de sécurité

  • Mot de passe long et unique : si un compte est piraté, les autres restent protégés.
  • Méfiance envers liens et pièces jointes : ils peuvent cacher des virus ou des arnaques.
  • Windows Defender actif : antivirus intégré qui bloque les menaces.
  • Se déconnecter : sur un PC partagé, pour que personne n'accède à vos comptes.
